Diagnostic — Pourquoi c'est lent ?
Lance un benchmark complet qui teste :
— Système : RAM, CPU, disque (vitesse lecture/écriture)
— E.TMS : réactivité des boutons LOG/NOTES/REFS, WinActivate, ControlSetText, Send
— Fichiers : accès EDS, dossier PJ, réseau partagé
— Réseau : serveur local, latences

Le rapport s'affiche dans une fenêtre avec les temps en ms et les problèmes identifiés.
Les logs sont sauvés dans logs/DIAG_*.log
